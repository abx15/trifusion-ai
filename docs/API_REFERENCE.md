# API Reference Index

The authoritative endpoint definitions are generated by NestJS Swagger at `/api/docs` when the API is running.

## Service endpoints

- NestJS liveness: `GET /health`
- NestJS readiness: `GET /ready`
- NestJS OpenAPI: `GET /api/docs`
- Django liveness: `GET /health`
- Django readiness: `GET /ready`

## Authorization boundary

Business and tenant authorization is enforced by NestJS guards and `PolicyService`. Django AI endpoints accept only signed internal service tokens and are not a replacement for the NestJS authorization boundary.
